Payment Help

Basic requirements for online payment

Payment through Debit Card / ATM Card / Credit Card

1. Debit Card / ATM Card / Credit Card.

2. Cardholder Name / Name on the Card.

3. Card Number (16 Digit).

4. Card Expiry Date (MM/YY).

5. Card CVV Number (3 Digit Behind the Card).

6. Registered Mobile Number.

Payment through Net Banking

1. User ID and Password of the Net Banking.

2. Registered Mobile Number.


Payment through UPI

1. UPI ID.

2. UPI Registered App.


Transaction fees clause

1. Transaction fees charged would not be refunded/ reversed for any refund or reversal and chargeback of any transaction.

2. Transaction fees charged would be borne by cardholder for any payment.

3. The School does not charge any transaction fee or GST.

4. Banks/IPG charge convenience fee against the fee collection facility.

5. GST is charged by Banks/IPG on the convenience fee only.
